<CardGrid>
  <Card title="A model that runs" icon="rocket">
    `evalBlock` takes encoded operand words and returns FP32 bits. It is
    ordinary Lean code that can be evaluated with `#eval`, compiled into
    batch checkers, and reasoned about in proofs.
  </Card>
  <Card title="Checked against an independent specification" icon="document">
    A separate transcription of Khattak and Mikaitis's model, `PaperSpec`, is
    proved to give the same output or rejection as `evalBlock` for **every**
    encoded input on all eight supported paths.
  </Card>
  <Card title="Replayed against GPU measurements" icon="laptop">
    35,000 recorded V100/A100/H100 measurements (FP16, BF16, TF32) are replayed
    through the Lean executable. The recorded result shows zero bit mismatches. [Coverage notes](/TC-EFT/model/validation/#what-the-rows-dont-cover).
  </Card>
  <Card title="Non-monotonicity and EFT" icon="random">
    Proved: in the constructed family, lowering C raises the output exactly when `K ≥ 3·2^p`.
    TC-EFT recovers the lost low-order parts and returns the correctly rounded
    sum when its stated preconditions hold.
  </Card>
</CardGrid>
